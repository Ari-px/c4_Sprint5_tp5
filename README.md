# 📚 Reader's Space - Gestor de Libros

Reader's Space es una aplicación web desarrollada con **React + Vite + TailwindCSS** que permite gestionar una colección de libros mediante un CRUD completo.

El proyecto consume una API REST creada con **MockAPI** (junto con mis lagrimas), permitiendo listar, ver detalles, crear, editar y eliminar libros.
Además, utiliza rutas dinámicas con React Router DOM, manejo de estado global con Context API, peticiones HTTP con Axios,
notificaciones con React Toastify y confirmaciones visuales con SweetAlert2.
